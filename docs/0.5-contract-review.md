# 0.5 contract and hardening review

Reviewed on 2026-10-09 against develop `4fd3dcd` and the published 0.4.0
artifact. Related to API #49 and hardening #50. Version/range updates and
coordinated candidate qualification remain release gates.

## Complete published inventory

The 0.4 root and `./monaco-editor` each expose the eleven editor names below;
`./testing` exposes two additional names. Decisions apply to both duplicate
entrypoints. The 0.5 root exposes three names, with no testing/component subpath.

| Path or name                   | Decision | Reason / migration                                                                                  |
| ------------------------------ | -------- | --------------------------------------------------------------------------------------------------- |
| `.`                            | KEEP     | Single import contract used by the website's interactive editor and documented integrations.        |
| `MonacoEditor`                 | KEEP     | The package's actual host component, used by the website and real-Monaco browser tests.             |
| `MonacoEditorProps`            | KEEP     | Wrapper-owned configuration and lifecycle contract, including model ownership and refs.             |
| `MonacoEditorOptions`          | KEEP     | Excludes wrapper-owned model/value/language/theme fields and prevents invalid construction options. |
| `MonacoEditorInstance`         | MOVE     | Native alias; use `monaco-editor`'s `editor.IStandaloneCodeEditor`.                                 |
| `MonacoTextModel`              | MOVE     | Native alias; use `editor.ITextModel`.                                                              |
| `MonacoUri`                    | MOVE     | Native alias; use `Uri`.                                                                            |
| `MonacoNamespace`              | MOVE     | Native alias; use `typeof import('monaco-editor/editor/editor.api')`.                               |
| `MonacoLoader`                 | MOVE     | Derive `MonacoEditorProps['loadMonaco']`; no independent consumer.                                  |
| `MonacoBeforeMount`            | MOVE     | Derive `MonacoEditorProps['beforeMount']`; no independent consumer.                                 |
| `MonacoMountHandler`           | MOVE     | Derive `MonacoEditorProps['onMount']`/`['onUnmount']`; no independent consumer.                     |
| `MonacoErrorHandler`           | MOVE     | Derive `MonacoEditorProps['onError']`; no independent consumer.                                     |
| `./monaco-editor`              | REMOVE   | Duplicate complete root contract; use root imports.                                                 |
| `./testing`                    | REMOVE   | Test-only ownership; use native editor/model edits in application tests.                            |
| `createMonacoEditorTestDriver` | MOVE     | Used only by this repository's browser harness; now private under tests.                            |
| `MonacoEditorTestDriver`       | MOVE     | Private type for the same helper; no demonstrated sibling consumer.                                 |
| `./package.json`               | KEEP     | Installed metadata; read by the packed consumer and compatibility tooling.                          |

Workspace search included all fetched sibling packages, examples, CLI templates,
website sources, docs, and tests. No sibling production consumer imports a
removed name or path. Local test imports and the testing guide were migrated.
The website's generated manifest/snapshot still describes installed 0.4
packages; regenerate it against the complete candidate set before API #49
closes. Do not add an unsupported Monaco dependency to `@askrjs/testing` merely
to relocate one repository's private helper.

## Executed probes

Existing assertions were inspected before adding tests. The new loader and
creation failure cases first failed against unchanged source (four failures,
including both obsolete resolve and reject outcomes, plus one unhandled
synchronous loader rejection).

| Invariant                                  | Evidence and outcome                                                                                                                                                                                                                                   |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Synchronous and rejected loader errors     | New jsdom assertions verify exact-once `onError`, null refs/no partial editor, and recovery with a new loader. Fixed synchronous exceptions escaping `onError`.                                                                                        |
| Stale loading generations                  | Resolve/reject obsolete loaders while their replacements remain pending; an intervening path/value update must not reload the replacement. Fixed obsolete completion clearing the current promise.                                                     |
| Latest model on delayed load               | Replace external models before the loader settles; only the latest model attaches and both caller-owned models survive teardown. Passed.                                                                                                               |
| Unmount during async work                  | Both loader resolve/reject after unmount are ignored, leave refs null, create no editor/model and invoke no stale callback. Existing delayed-beforeMount test also verifies remount recovery. Passed.                                                  |
| Failed editor creation                     | New test verifies immediate exact-once owned-model disposal, URI deregistration and later successful recreation. Fixed retained owned model. Additional external-model failure test verifies caller ownership.                                         |
| Replacement and cleanup                    | Existing eight successive path changes dispose each superseded model exactly once; existing external replacement preserves caller models. New eight-mount loop verifies listener, model/editor cleanup, null refs and no later prop mutations. Passed. |
| Native edit boundaries and driver ordering | Real Monaco on Chromium desktop, Pixel 7, Firefox and WebKit: empty edits, out-of-range clamping, two queued drivers with deterministic undo order, and stale driver rejection after unmount. Passed.                                                  |
| Installed contract and SSR                 | Normal packed install with Askr 0.4.0 and Monaco 0.56.0; root runtime/types resolve, SSR emits only its host without loading Monaco, removed aliases/helpers/paths fail resolution. Passed.                                                            |
